# Politica de Seguridad

## Politica de Divulgacion Responsable
El tratamiento de datos geograficos precisos de los vecinos e identidades de usuario es una prioridad absoluta para este proyecto de ciencia ciudadana. Si usted identifica una vulnerabilidad de seguridad o un fallo en el manejo de Datos de Identificacion Personal (PII) dentro del sistema, le solicitamos que actue de manera responsable y no abra un Issue publico en GitHub.

En su lugar, proceda a realizar un reporte privado enviando un correo electronico detallado a la direccion del equipo de desarrollo (devops-team-emergencias@ejemplo.com) para que podamos analizarlo, verificarlo y mitigarlo de forma segura.

## Versiones Soportadas
Actualmente solo se proporciona soporte de seguridad y parches para las ramas principales de integracion activas:

| Version | Soportada |
| :--- | :--- |
| develop / main (Ultimo Commit) | Si |
| Ramas de Feature locales | No |

## Proceso de Reporte y Mitigacion
Por favor incluya en su correo de reporte privado:
1. Una descripcion clara de la vulnerabilidad identificada.
2. Pasos detallados para reproducir el fallo de seguridad (conceptos de prueba o ejemplos si aplica).
3. El impacto potencial estimado sobre el sistema o los datos de los vecinos.

El Equipo PM respondera a su reporte en un plazo maximo de 48 horas habiles indicando los pasos a seguir para la mitigacion y resolucion de la vulnerabilidad en las ramas de integracion.
